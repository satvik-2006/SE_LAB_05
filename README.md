# SE Lab 05 - Static Code Analysis

This repository contains the final submission and the before/after evidence for Lab 5.

## Main deliverables

- `Lab_5_Static_Code_Analysis_Report.pdf` - report, test results, screenshots, issue table, and reflections.
- `scheduler_system.py` - cleaned scheduler program.

## Evidence layout

- `before/` - starter code, captured tool reports, program output, and generated screenshots.
- `after/` - corrected code, captured tool reports, behavior checks, program output, and generated screenshots.
- `issues.md` - summary of findings and fixes.

The screenshots are generated terminal-style and source views based on the saved code and captured tool output.
